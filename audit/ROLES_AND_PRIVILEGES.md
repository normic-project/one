# Roles and privileges

| Role | Authority |
| --- | --- |
| Any address | Create event markets; place, match, and cancel orders; redeem owned shares |
| Creator | Define immutable terms and claim accrued 0.6% creator fees |
| Treasury | Receive listing fees and 0.4% protocol trading fees |
| Resolver Safe | Select one final YES, NO, or INVALID outcome after the resolution timestamp |

No role can upgrade contracts, replace the implementation, edit market terms, seize shares, or withdraw trader collateral.
